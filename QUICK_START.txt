📋 INSTALLATION (5 MINUTES)
═══════════════════════════════════════════════════════════════

1. INSTALL PYTHON 3.9+
   Download from: https://www.python.org/downloads/
   ✓ Check "Add Python to PATH" during installation

2. INSTALL MT5
   Download from your broker's website
   ✓ Create a DEMO account (NOT real money!)
   ✓ Write down: Login, Password, Server name

3. INSTALL DEPENDENCIES
   Open Command Prompt in project folder:
   
   cd alogo_traderobot\backend
   pip install -r requirements.txt
   
   Wait for installation to complete (~2-3 minutes)


⚙️ CONFIGURATION (2 MINUTES)
═══════════════════════════════════════════════════════════════

1. EDIT backend\.env FILE
   Open with Notepad and change:
   
   MT5_LOGIN=12345678              ← Your MT5 demo account number
   MT5_PASSWORD=your_password      ← Your MT5 demo password
   MT5_SERVER=YourBroker-Demo      ← Your broker server name
   
   ACCOUNT_SIZE=15.0               ← Your demo balance
   DEMO_ONLY=True                  ← KEEP THIS TRUE for safety!

2. VERIFY MT5 IS RUNNING
   ✓ Open MetaTrader 5 terminal
   ✓ Make sure you're logged in
   ✓ Check "AutoTrading" button (top toolbar) is GREEN


🚀 START THE ROBOT
═══════════════════════════════════════════════════════════════

METHOD 1: Double-click START_ROBOT.bat

METHOD 2: Command line
   cd backend
   python trading_bot.py

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "MT5 initialize failed"
   → Make sure MT5 is running
   → Check "AutoTrading" is enabled (green)

❌ "Symbol not found"
   → Open MarketWatch in MT5 (Ctrl+M)
   → Right-click → Symbols → Add your symbol

❌ "Trading not allowed"
   → Check MT5 connection (bottom right should be green)
   → Verify demo account is active

❌ "No signals"
   → This is normal! Good signals are rare
   → Wait 1-2 days for market movement
   → Check logs for "Channel Detected" messages
